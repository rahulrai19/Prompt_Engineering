# Clarity & Specificity

## Concept
Vague prompts get vague code. Being explicit about the task, format,
constraints, and edge cases turns a generic first draft into something
actually shippable.

## Why it matters for developers
The gap between a vague and a specific prompt shows up directly in code
quality: type safety, error handling, and whether the output actually
matches your real requirements instead of a generic guess.

## Test Prompts

### Vague prompt
```
Write a function to validate a password.
```

### Specific prompt
```
Write a TypeScript function `validatePassword(password: string): { valid: boolean; errors: string[] }` that checks:
- minimum 8 characters
- at least one uppercase letter
- at least one lowercase letter
- at least one digit
- at least one special character from !@#$%^&*

Return ALL failing reasons in the errors array, not just the first one.
No external libraries — use only built-in string methods and regex.
Include a JSDoc comment above the function.
```

#  Evaluation & Iteration

## Concept
Treat prompt changes like code changes: build a small test set, run it,
score it, and only then decide a change is actually an improvement — not
by eyeballing one output.

## Why it matters for developers
A prompt that "seems better" on one example can easily be worse on
another. Without a scored test set, you're optimizing on vibes, and
regressions slip in silently.

## Test Prompts

### Version 1 — bare
```
Review this code: [snippet]
```

### Version 2 — structured
```
You are a senior code reviewer. Review the following code for three
categories: (1) security vulnerabilities, (2) performance issues,
(3) readability/naming. For each category, either flag a specific issue
or state "no issues found". Use this exact format:

Security: ...
Performance: ...
Readability: ...

Code: [snippet]
```

### Test Snippets
```python
# Test 1 — security
def get_user(username):
    query = f"SELECT * FROM users WHERE username = '{username}'"
    return db.execute(query)

# Test 2 — performance
def has_duplicates(lst):
    for i in range(len(lst)):
        for j in range(len(lst)):
            if i != j and lst[i] == lst[j]:
                return True
    return False

# Test 3 — readability
def f(x, y, z):
    a = x * y
    b = a + z
    return b
```

## Scoring Method
For each test × version, score whether Security/Performance/Readability
was explicitly addressed: full / partial / missed. Tally out of 9 total
per version per platform (3 categories × 3 tests).

## Results Log

| Platform | Version 1 score (out of 9) | Version 2 score (out of 9) | Notes |
|----------|--------------------------------|--------------------------------|-------|
| Claude   | ~7 (2 full + 1 partial: readability naming issue not explicitly named in Test 3) | 9 (full coverage on every test) | Structured prompt guarantees consistent coverage regardless of what's most salient |
| ChatGPT  |                                |                                | Not tested |
| Gemini   |                                |                                | Not tested |

## Takeaway
Structured Version 2 didn't necessarily produce "smarter" reviews — it
guaranteed consistent coverage across all three categories every time,
while Version 1's quality depended on which issue happened to be most
salient to the model. _Fill in ChatGPT/Gemini scores once tested — worth
checking whether the gap between versions is bigger or smaller on those
platforms._

#  Agentic Workflows

## Concept
The simplest agentic pattern is a 2-step chain: generate something, then
feed that output back into a fresh prompt to review it. Chaining catches
issues a single generation pass tends to miss, and tests something
interesting on top: how well a model catches its own mistakes on review.

## Why it matters for developers
Real agentic systems are built from exactly this kind of chaining —
breaking one task into a pipeline of smaller prompts, each with a narrow,
well-defined job, rather than asking for everything in one shot.

## Test Setup

### Step 1 — Generate
```
Write a Python function parse_csv_line(line: str) -> list[str] that splits
a single CSV line into fields, correctly handling fields wrapped in double
quotes that may contain commas inside them.
```

### Generated Output (has a bug)
```python
def parse_csv_line(line: str) -> list[str]:
    fields = []
    current = ""
    in_quotes = False
    for char in line:
        if char == '"':
            in_quotes = not in_quotes
        elif char == ',' and not in_quotes:
            fields.append(current)
            current = ""
        else:
            current += char
    fields.append(current)
    return fields
```
Handles commas inside quotes, but misses the CSV escaping rule: a doubled
quote (`""`) inside a quoted field represents one literal quote character.
On `"She said ""hello"""` this drops the quote characters entirely.

### Step 2 — Review (feeding Step 1's output back in)
```
Review the following function for edge cases and bugs, specifically around
CSV escaping rules:

[paste the generated function]

Test cases to consider: fields with embedded commas, fields with escaped
quotes ("" representing a literal quote character), and fields with
leading/trailing whitespace.
```

### Corrected Output (after review)
```python
def parse_csv_line(line: str) -> list[str]:
    fields = []
    current = ""
    in_quotes = False
    i = 0
    while i < len(line):
        char = line[i]
        if char == '"':
            if in_quotes and i + 1 < len(line) and line[i + 1] == '"':
                current += '"'
                i += 2
                continue
            in_quotes = not in_quotes
        elif char == ',' and not in_quotes:
            fields.append(current)
            current = ""
        else:
            current += char
        i += 1
    fields.append(current)
    return fields
```
